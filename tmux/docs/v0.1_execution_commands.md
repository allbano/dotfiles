# Comandos executados — helper de transparência v0.1

## Finalidade e convenções

Este arquivo consolida os comandos usados no planejamento, implementação e
validação do helper. Comandos idênticos ou muito semelhantes aparecem em uma
única família; quando foram repetidos, o texto registra os momentos e os
resultados sem repetir a mesma explicação.

Todos os blocos `bash` abaixo foram efetivamente executados. Os arquivos foram
editados pela ferramenta de aplicação de patches, não por redirecionamento de
shell. Consultas feitas no navegador são separadas no fim porque não são
comandos de terminal.

```text
Repositório: /home/albano/github/dotfiles
Branch: archlinux
Shell: bash
Data: 2026-07-31
Fuso horário: America/Sao_Paulo
Sessão gráfica: Wayland / KDE
Prefixo tmux: C-Space
Binding: C-Space, soltar, Shift+A
```

## Resultado consolidado

- Helper criado em `scripts/toggle-terminal-transparency`.
- Binding `A` adicionado ao tmux sem mudar sua barra de status.
- Ghostty, Kitty e Alacritty testados em ciclos `0.8 -> 1.0 -> 0.8`.
- Testes automatizados e validadores dos três terminais aprovados.
- Estado final do Ghostty restaurado para `0.8`.
- Diretório de estado Ghostty com modo `700` e arquivo com modo `600`.
- Binding carregado nos servidores tmux que estavam ativos.
- A instância Kitty aberta antes da mudança ainda requer reinicialização para
  adquirir `KITTY_LISTEN_ON`.
- `shellcheck` não estava instalado; foram usados `bash -n`, fixtures, mocks e
  testes funcionais reais.
