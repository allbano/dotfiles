## 4. Implementação da correção

### 4.1 Edição em `scripts/change-terminal-font`

Adicionada função `ensure_fzf_path()` após `ensure_system_sbin_path()`:

~~~bash
ensure_fzf_path() {
    local fzf_bin

    for fzf_bin in "${HOME}/.fzf/bin" "${HOME}/.local/share/fzf/bin"; do
        if [[ -d "$fzf_bin" ]]; then
            case ":${PATH:-}:" in
                *":${fzf_bin}:"*) ;;
                *) PATH="${fzf_bin}${PATH:+:${PATH}}"; export PATH ;;
            esac
            return 0
        fi
    done
}
~~~

E adicionada chamada após `ensure_system_sbin_path`:

~~~bash
ensure_system_sbin_path
ensure_fzf_path
~~~

### 4.2 Edição em `scripts/toggle-terminal-transparency`

Mesma função `ensure_fzf_path()` adicionada, mantendo consistência entre
os dois helpers de terminal.

## 9. Comportamento esperado após o fix

1. Usuário pressiona `prefix + F` no kitty (ou qualquer terminal)
2. tmux executa `run-shell -b` → expande formatos → chama `display-popup`
3. `display-popup` abre com PATH mínimo (sem `.zprofile`/`.bash_profile`)
4. Script `change-terminal-font` executa `ensure_fzf_path()`
5. `~/.fzf/bin` é adicionado ao PATH
6. `require_command fzf` encontra o binário
7. Seletor de fontes abre normalmente
8. Se usuário cancelar (Esc), retorna 130 → tmux mostra "returned 130" (esperado)
